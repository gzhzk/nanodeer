# 核心概念

理解 NanoDeer，只需要掌握 5 个核心概念。

## 1. Agent（智能体）

Agent = **大脑**，负责思考和决策。

```
用户输入 → Agent 思考 → 需要执行操作？ → 调用 Tools
                  → 需要记住？ → 访问 Memory
                  → 需要分解任务？ → 使用 Plan
                  → 返回结果给用户
```

**NanoDeer 的 Agent 用 LangGraph 实现**，是一个状态机。

## 2. Tools（工具）

Tools = **手和脚**，让 Agent 能执行实际操作。

| 类别 | 工具 | 作用 |
|------|------|------|
| 文件 | WriteFile, ReadFile | 读写文件 |
| 目录 | Ls, Glob, Grep | 搜索文件 |
| 命令 | Bash | 执行 Shell 命令 |
| 网络 | FetchUrl, WebSearch | 抓取网页/搜索 |
| 代码 | ExecPython | 执行 Python 代码 |
| 图像 | ReadImage | 读取图像 |
| 记忆 | SaveMemory | 保存记忆 |
| 规划 | WriteTodo, ListTodos | 任务管理 |
| 技能 | InvokeSkill | 调用技能 |

## 3. Middleware（中间件）

Middleware = **拦截器**，在 Agent 执行过程中插入钩子。

```
请求进入
    ↓
before_agent_start: 创建目录 → 初始化沙箱 → 安全校验 → ...
    ↓
[Agent 执行...]
    ↓
after_agent_end: 清理沙箱 → 保存状态 → ...
```

**为什么需要中间件？**
- 不修改 Agent 核心逻辑
- 每个中间件只管一件事
- 可插拔，按需启用

## 4. Sandbox（沙箱）

Sandbox = **隔离环境**，确保 Agent 操作安全。

```
宿主机
    └── Docker 容器（隔离）
            └── Agent 在容器内执行命令
            └── 无法访问宿主机敏感文件
            └── 操作有 timeout，防止死循环
```

**核心优势：**
- 隔离安全：恶意代码无法逃逸
- 环境一致：每次都是干净容器
- 资源可控：CPU/内存/网络均可限制

## 5. Memory（记忆）

Memory = **海马体**，让 Agent 跨会话记住重要信息。

```
~/.nanodeer/memory/
└── {user_id}/
    ├── user.md              # 用户偏好（跨项目共享）
    └── project/
        └── {project}.md    # 项目上下文
```

**注入时机：**
- `before_agent_start`：加载历史记忆到 Agent 上下文
- `after_agent_end`：自动提取关键信息保存

## 概念关系图

```
┌─────────────────────────────────────────────────────────┐
│                        用户请求                          │
└──────────────────────────┬──────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│                      Agent (大脑)                        │
│  - 接收请求                                            │
│  - 思考决策                                            │
│  - 调用 Tools                                          │
└──────────┬──────────────────────────┬──────────────────┘
           │                          │
           ▼                          ▼
┌──────────────────┐      ┌──────────────────────────────┐
│     Tools        │      │       Middleware             │
│   (手和脚)        │      │  (拦截器: 目录/沙箱/安全...)  │
└──────────────────┘      └──────────────────────────────┘
           │                          │
           ▼                          ▼
┌──────────────────┐      ┌──────────────────────────────┐
│    Sandbox       │      │         Memory               │
│   (隔离执行)      │      │      (跨会话记忆)            │
└──────────────────┘      └──────────────────────────────┘
```
